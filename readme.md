## Kendala yang Dihadapi dan Cara Mengatasinya
Selama proses pembuatan website, terdapat beberapa kendala yang dihadapi, antara lain:

### A.Kesalahan Penulisan Kode HTML
**Kendala:** Beberapa bagian HTML mengalami kesalahan penulisan atribut dan ketidaksesuaian ID sehingga elemen tertentu tidak berfungsi dengan baik.
**Cara mengatasi:** Memeriksa kembali kode HTML dan memperbaiki penulisan atribut serta menyamakan ID antara HTML dan JavaScript.

### B.Tampilan Website Tidak Sesuai
**Kendala:** Beberapa elemen website tidak tersusun sesuai dengan desain yang diharapkan, terutama ketika ditampilkan pada ukuran layar yang berbeda.
**Cara mengatasi:** Memperbaiki aturan CSS serta menggunakan Flexbox, Grid, dan Media Query agar tampilan lebih teratur dan responsif.

### C.Menu Navigasi pada Perangkat Mobile
**Kendala:** Menu navigasi belum dapat dibuka dan ditutup dengan baik pada tampilan telepon genggam.
**Cara mengatasi:** Menambahkan tombol hamburger dan menggunakan JavaScript dengan `classList.toggle()` untuk mengatur tampilan menu.

### D.Fitur Pencarian dan Filter Proyek
**Kendala:** Fitur pencarian dan filter belum dapat mengenali kategori setiap proyek.
**Cara mengatasi:** Menambahkan atribut `data-kategori` pada setiap kartu proyek dan menyesuaikan kode JavaScript agar pencarian dan filter
dapat berjalan sesuai kategori.

### E.Kesalahan Penghubung File
**Kendala:** Beberapa file CSS dan JavaScript perlu disesuaikan alamat pemanggilannya agar dapat terhubung dengan halaman HTML.
**Cara mengatasi:** Memeriksa kembali lokasi file dan memperbaiki alamat pada atribut `href` dan `src`.
